# 数据迁移与回滚

## Schema 13

- 课程布局增加 `teach_strength`、`problem_strength`，默认 `medium`。
- run 增加档位、B、预计费用和应用美元上限快照；最高档的上限允许 NULL。
- 增加用户主题偏好表。
- 迁移幂等；旧 Bridge、Pair、消息、资格、文件、课程树、覆盖和测评数据不删除。
- 检测到比当前代码更新的 Schema 时拒绝降级启动。

## 发布前演练

1. 停止写入或进入维护窗口，记录应用 SHA 与数据库路径。
2. 生成数据库一致性备份及上传目录清单/哈希。
3. 在隔离副本运行 Schema 13，核对行数、外键和关键用户流程。
4. 构建并部署同一冻结 SHA，执行健康检查与只读 smoke。
5. 小范围真实用户验证后再解除维护窗口。

## 回滚

- 应用异常但 Schema 13 正常：回滚到明确支持 Schema 13 的构建。
- 旧构建不支持 Schema 13：不能直接指向已迁移数据库；恢复发布前数据库备份和匹配
  的上传目录，再切回旧构建。
- 主题与强度字段可向前保留；不得为回滚删除旧 Bridge、资格或历史记录。

本轮仅在合成数据库演练，没有迁移生产数据库。

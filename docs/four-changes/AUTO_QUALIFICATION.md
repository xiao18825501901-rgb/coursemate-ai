# 注册自动学生资格

## 新政策

`CMUI_CAMPUS_QUALIFICATION_POLICY=registered_active`。通过有效身份进入系统的活动
普通用户在同一请求内取得并持久化 `registered` 资格，因此首次读取、创建 Pair、
加入校园课程与开始学习不依赖异步 webhook 的第二次尝试。

## 保留规则

- 已认证用户保留 `grandfathered`、`code`、`admin` 等原来源，不被 `registered` 覆盖。
- 本地目录明确 disabled 的身份不会被自动复活。
- 普通用户不会取得管理员权限。
- 七位码、兑换记录和资格审计表继续保留。
- 自动资格不自动 pin 所有课程；用户仍需自行添加课程。

## 迁移边界

这是按活动登录/访问懒迁移并持久化的政策，不对删除或禁用身份做批量复活。
生产发布前应只读统计未认证且活动的候选集合；生产写入须随应用发布和数据库备份
一起执行，不能以旧快照重新 fetch 后直接 apply。

# 推理强度策略

- 两个 Pane 各有一个可访问的图标式选择器，默认“中”。
- 支持刻度点击、拖动、键盘与触屏；选中后立即写入课程布局。
- 提交时将当时档位写入 run，进行中的 run 不受后续 UI 变化影响。
- 左栏 Thinking 与推理强度正交；右栏没有被强制打开供应商 Thinking。
- run 保存 `reasoning_strength`、B、预计成本及最终应用上限快照，便于费用审计。
- config 只公开档位枚举，不公开密钥或供应商凭据。
- `max` 只取消 CourseMate 的美元硬上限，不承诺无限 token、无限账户余额或无限供应商配额。

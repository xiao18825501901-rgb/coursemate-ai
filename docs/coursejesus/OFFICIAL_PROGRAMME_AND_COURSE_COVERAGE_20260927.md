## 未完成覆盖的准确原因

1. 当前匿名 `All Courses` 页面没有返回动态课程行。
2. 专业详情中的建议学习计划以图片或 cohort CIR 为准，不能可靠提取为逐课程官方目录。
3. CourseJesus 本地清单包含历史学期和香港主校资料；不能仅凭相同 course code 认定为东莞同一版本。

因此本表完成了当前招生专业、跨年度差异和静态 Gateway 课程覆盖；“全部专业的完整 cohort 课程矩阵”保持 `PARTIAL / REQUIRES CIR OR AUTHENTICATED SIS`。

## 为什么没有直接发布九月提交

当前生产数据库包含截止日以后创建的课程、消息、练习、题目修订、测评、成绩、模型用量与
UNKNOWN 审计。九月程序的 schema 声明早于当前结构，直接启动既不能证明它会保留新增字段，
也不能证明历史读写兼容。恢复工程因此采用：

1. 独立工作树，不重置共享工作区；
2. 生产数据库只读盘点和持久备份；
3. 在隔离副本上验证 schema 81/16/3；
4. 只增加向前兼容，不做逆向迁移；
5. 每一阶段先冻结候选，再做真实 Clerk 学生验收。
